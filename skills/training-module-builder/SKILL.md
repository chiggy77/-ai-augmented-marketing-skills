# Training module builder

## Steps
1. Ask for the audience, duration, the tool or playbook, and what learners should be able to do afterwards.
2. Copy `templates/module.md` and fill every section. Learning goals start with a verb a learner can demonstrate.
3. Make the agenda minutes add up to the duration, with at least half the time hands-on.
4. Write an exercise with a clear expected result and the common mistakes.
5. Add 3 to 5 questions with answers.
6. Say honestly whether the module has been delivered or tested with learners.

## Rules
- Plain English, no jargon without a definition.
- One tool or idea per module.
- Include how learners will get help after the session.
